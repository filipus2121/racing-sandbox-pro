# racing-sandbox-pro

2D top-down racing simulator: full rigid-body Pacejka vehicle model, four wheels with
load transfer, suspension and a differential, and physics-based AI opponents that
steer, brake and make mistakes rather than follow a scripted path.

## Запуск

Нужен Node.js 18+ (проверено на 22).

```bash
git clone https://github.com/filipus2121/racing-sandbox-pro.git
cd racing-sandbox-pro
npm ci
npm run dev
```

Откроется на `http://localhost:5173`.

### Остальные команды

| Команда              | Что делает                                    |
| -------------------- | --------------------------------------------- |
| `npm run dev`        | dev-сервер Vite                               |
| `npm run typecheck`  | `tsc --noEmit`                                |
| `npm test`           | прогон vitest                                 |
| `npm run build`      | typecheck + production-сборка в `dist/`       |

Диагностика физики и ИИ запускается отдельно, вне браузера:

```bash
npx vite-node tools/diag27.ts 14 6   # Daytona, 14 машин, 6 кругов
```

## Управление

Геймпад поддерживается: стик — руль, RT/LT — газ/тормоз, A — ручной тормоз,
бамперы — переключение передач.

Езда (`src/input.ts`):

| Клавиша            | Действие        |
| ------------------ | --------------- |
| `W` / `↑`          | газ             |
| `S` / `↓`          | тормоз          |
| `A` / `←`          | руль влево      |
| `D` / `→`          | руль вправо     |
| `Space`            | ручной тормоз   |
| `Shift` / `E`      | передача вверх  |
| `Ctrl` / `Q`       | передача вниз   |
| `C` (удерживать)   | сцепление       |

Интерфейс (`src/main.ts`):

| Клавиша   | Действие                     |
| --------- | ---------------------------- |
| `O`       | экран настройки машины       |
| `T`       | приглушить телеметрию        |
| `L`       | гоночная траектория          |
| `M`       | миникарта                    |
| `V`       | отладочный оверлей ИИ        |
| `C`       | заблокировать камеру         |
| `P`/`Esc` | пауза                        |
| `R`       | перезапустить сессию         |

`C` занята дважды — и как сцепление (по удержанию), и как переключение камеры
(по нажатию). Клавиши запроса пит-стопа пока нет.

## Что сейчас работает в браузере

Трек **Daytona Oval** (2.500 мили, триовал, повороты 31°) выбирается в меню и стоит
первым по умолчанию; машина **NASCAR Next Gen** доступна в списке.

Подключено к UI: трек, физика, ИИ-соперники, телеметрия, экран настройки машины.

Пока **не** подключено к UI — логика написана и проверена через `tools/diag27.ts`
в Node, но не выведена в браузер:

- пит-лейн, пит-стопы и анимация бригады (`main.ts` не передаёт `pitDef`);
- отрисовка pace car, флагов, обломков и формации рестарта (`renderer.ts`);
- показания флага / кругов до финиша / пит-стопа в HUD;
- на овале ИИ пока едет на смешанных машинах (`aiSpecs: Object.values(CAR_SPECS)`).

Известно также, что рестарт после жёлтого не доведён: в симуляции поле рассыпается
после первого пейс-кара.

## Архитектура

```
src/core/math.ts          математика, RNG с сидом
src/physics/tire.ts       Pacejka (magic formula) + комбинированное скольжение
src/physics/vehicle.ts    жёсткое тело, 4 колеса, подвеска, дифференциал (500 Гц)
src/physics/cars.ts       спецификации машин и шин
src/track/track.ts        полотно трека, бэнкинг, покрытие, погода
src/track/racingLine.ts   гоночная траектория и скоростной профиль
src/ai/opponent.ts        водитель: линия, торможение, обгоны, ошибки
src/ai/follow.ts          общий контроллер следования по точке
src/state/world.ts        сессия: физика, столкновения, границы, standings
src/state/pit.ts          пит-лейн и обслуживание
src/state/raceControl.ts  флаги, пейс-кар, овертайм, рестарт
```
